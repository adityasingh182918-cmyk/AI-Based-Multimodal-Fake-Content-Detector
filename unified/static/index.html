Local privacy controls
History and input retention
⌑
What is saved
Every analysis saves its result, model/checkpoint version, timestamp, processing time, and hashes of supplied inputs in the local SQLite database. By default, raw text and image bytes are not retained. If retention is enabled in the server environment, text is stored in SQLite and images are stored in a private, non-static folder. History can be viewed, exported, and deleted here.
